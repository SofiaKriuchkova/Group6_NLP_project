# Self-Referential Gender Switching in Russian LLM Dialogue

A research project exploring how large language models express grammatical gender in Russian self-referential dialogue.

Russian provides a useful setting for this analysis because first-person past-tense forms can explicitly encode speaker gender:

- **понял** — masculine
- **поняла** — feminine

This project investigates how different LLMs use these forms across conversational contexts.
